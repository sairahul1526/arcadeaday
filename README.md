## Layout

```
games/                 everything here is deployed as-is (static, no build step at deploy time)
  games.json           source of truth: game list + SEO copy (how to play, tips, FAQ, shop prices)
  index.html           hub, GENERATED by tools/build-site.mjs
  404.html, sitemap.xml, robots.txt, <indexnow-key>.txt   GENERATED
  site.css             shared styles: hub, 404 and the info sheet under each game
  _headers             noindex for www and *.pages.dev (only arcadeaday.com is indexed)
  <slug>/              one folder per game: index.html, game.js, audio.js, og.jpg
                       index.html's <!-- build:head --> and <!-- build:body --> blocks are GENERATED
tools/
  build-site.mjs       regenerates hub, game page SEO blocks, sitemap, 404 (run after editing games.json)
  keywords.mjs         keyword research: DataForSEO if .env has creds, else Google autocomplete
  indexnow.mjs         pings IndexNow (Bing etc.) with the sitemap URLs after a deploy
  record.mjs           deterministic gameplay recorder: 1080x1920 60fps MP4 + offline-rendered soundtrack
  og.mjs               1200x630 share image from a game's title screen (`hub` for the hub)
```

## Run locally

```bash
npm install
npx http-server games -p 8787 -c-1
```

## Record a video

Each game supports `?record=1`: fixed timestep, a scripted bot, and audio rendered offline from the event log.

```bash
node tools/record.mjs kiss-the-edge --query "seed=11&crash=22&hook=the music only gets better|if you ALMOST crash"
```

## Deploy

```bash
node tools/build-site.mjs
npx wrangler pages deploy games --project-name onemoretry-games --branch main --commit-dirty=true
node tools/indexnow.mjs
```

## SEO

Each game page is a full-screen game with a crawlable info sheet one screen below it (title,
how to play, controls, tips, shop prices, FAQ, related games) plus VideoGame/FAQ/Breadcrumb JSON-LD.
All of it comes from the game's `seo` block in `games/games.json`. For keyword research, put
DataForSEO creds in `.env` (gitignored):

```
DATAFORSEO_LOGIN=...
DATAFORSEO_PASSWORD=...
```
